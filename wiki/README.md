# PureMath Wiki Source

This directory contains the Wiki-style documentation source for PureMath.

The pages are intentionally kept separate from the formal specification in `spec/`.

- `wiki/`: user-facing language documentation
- `spec/`: semantic and architectural specification
- `examples/`: executable source examples

The documentation describes the current prototype and should not be read as a claim of full KaTeX compatibility or a finished production language.

The repository's formal semantic baseline remains `spec/SPEC-v0.1.md`.
